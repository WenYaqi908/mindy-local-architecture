# TabBar 图标说明

此目录需要放置底部导航栏的图标文件。

## 需要的图标文件（共8个）

1. **home.png** - 首页图标（未选中）
2. **home-active.png** - 首页图标（选中，红色 #FF2442）
3. **recommend.png** - 推荐图标（未选中）
4. **recommend-active.png** - 推荐图标（选中，红色 #FF2442）
5. **news.png** - 资讯图标（未选中）
6. **news-active.png** - 资讯图标（选中，红色 #FF2442）
7. **mine.png** - 我的图标（未选中）
8. **mine-active.png** - 我的图标（选中，红色 #FF2442）

## 图标规格

- **尺寸**: 81px × 81px（建议使用 40.5pt × 40.5pt）
- **格式**: PNG
- **背景**: 透明
- **未选中颜色**: #999999
- **选中颜色**: #FF2442（小红书红）

## 临时解决方案

目前可以使用以下emoji作为图标：
- 首页: 🏠
- 推荐: ⭐
- 资讯: 📰
- 我的: 👤

## 注意事项

请确保图标文件命名正确，否则底部导航栏可能无法正常显示。
