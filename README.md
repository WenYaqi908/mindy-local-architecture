# 心享本地测试

这是一台 Mac 上的本地验收环境，用来给老师看当前结构和试本地代码。线上库、线上短信和云端实时语音都没有接。

## 两张图

- [空间架构](docs/空间架构.md)：手机、入口、业务服务、数据库、音频和本地语音各在哪里。
- [流程架构](docs/流程架构.md)：从登录、听读、聊天到听记，按时间怎么走。

进度说明在 [给老师的进度说明.md](给老师的进度说明.md)。`框架.png` 和 `框架2.png` 是原来的目标图。上面两张图画的是现在实际跑起来的样子。

## 仓库里有什么

- `phone-app/`：iPhone 外壳。它打开本机加密页面，并把麦克风和播放交给页面。
- `tools/mindy-local-k8s/`：本地 Kubernetes 清单、页面镜像材料、建库脚本和备份脚本。
- `tools/local-realtime-voice.py`：本地语音替身。识别用 Whisper Small，回答用 Qwen2.5 3B，朗读用 macOS 的 say。
- `product-delta/`：页面仓库和业务仓库里还没提交的本地改动。基线都是 `feature/english-version`。这里不是两套完整产品代码。

## 没有放进来的东西

私钥、备份密钥、加密备份、模型权重、JDK、Node、MySQL 安装包和构建产物留在这台 Mac 上。本地清单里的数据库口令只用于这个测试库，不是线上口令。仓库请保持私有。
